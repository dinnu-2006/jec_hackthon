# Background Video Folder

Place your website background video file here.

### Supported Formats & Recommended Naming:
- `hero_background.mp4` (Recommended: H.264 / MP4 format, 1080p, 30/60fps)
- `hero_background.webm` (Optional WebM format for extra browser optimization)

### How It Works:
The hero section automatically detects and plays `/video/hero_background.mp4` in a seamless loop (`autoPlay loop muted playsInline`). If no video file is provided or while loading, it automatically falls back to the cinematic artwork image (`/assets/john_wick_hero_bg.png`).
